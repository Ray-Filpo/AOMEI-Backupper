## ✨ What You Can Do With AOMEI-Backupper

### 🗂️ Back Up Files and Folders
Select the documents, photos, videos, or entire folders you care about, choose a destination such as an external drive or a second internal disk, and create a copy. You can repeat this whenever you like, and each copy stays separate so an older version is always available if a newer one is damaged.

### 💽 Back Up an Entire Disk or Partition
If you want a complete safety net, you can copy a whole disk or a single partition. This captures everything on that drive in one operation, which is useful before making major changes to your computer.

### 🔄 Restore Anything You Backed Up
When something goes wrong — a deleted folder, a corrupted drive, a failed update — you open the application, point it at your backup, and restore. You can restore everything at once or pick only the specific files you need.

### 🧩 Resize, Merge, and Split Partitions
Free space on one drive while another is full? The partition tools let you shrink a partition, extend it into unused space, merge two partitions into one, or split a large partition into two smaller ones. All of this happens through a visual layout of your drives, so you can see exactly what will change before you confirm.

### 🖥️ Move Windows to a New Drive
When you upgrade to a larger or faster drive, you do not need to reinstall Windows or reinstall all your programs. The OS migration feature copies your entire Windows setup, including your applications and personal files, to the new drive so the computer starts up exactly as it did before.

### 🛠️ Recover Lost or Deleted Partitions
If a partition disappears after a mistake or a system problem, the recovery feature scans the drive and helps you bring that partition back so its contents become accessible again.

### 📊 Manage Disks in One Place
A single overview screen shows every drive connected to your computer, how large each one is, how much space is free, and what file system it uses. From that screen you can start any of the operations above without hunting through menus.

## 🖱️ Everyday Use Tips

- **Keep backups on a separate physical drive.** A copy stored on the same disk does not help if that disk fails.
- **Create a backup before big changes.** Installing a new operating system update, resizing a partition, or replacing hardware are all good moments for a fresh copy.
- **Label your backups clearly.** A name like "Photos-January" tells you far more than "Backup1".
- **Check your backups occasionally.** Restore a single unimportant file now and then to confirm everything works as expected.
- **Disconnect external drives when finished.** This reduces the chance of accidental changes and keeps the drive healthy.

## ❓ Common Questions

**Do I need to know anything about computers to use this?**
No. Every action is a button or a dropdown. The application explains what each option does as you go.

**Where should I save my backups?**
An external USB drive is the simplest choice for most people. A second internal drive works well too, as long as it is not the same drive holding the original files.

**Can I use the application on more than one computer?**
You can download it on each Windows computer you own and follow the same short setup each time.

**What happens if I close the application during a backup?**
The operation stops. Simply open the application again and start the backup fresh — nothing on your original files is altered by an interrupted copy.

**Will my files be changed during a backup?**
No. Backing up only reads your files and writes copies to the destination you selected.

**How often should I back up?**
For important work files, once a week is a sensible habit. For photos and personal documents, once a month plus before any major change to your computer is usually enough.
